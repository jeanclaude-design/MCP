# Projet MCP FastAPI avec assistant vocal

Ce projet contient un serveur MCP en FastAPI, des agents de recherche PDF, d'envoi Gmail, de veille Web et un assistant vocal local basé sur Whisper.

Lancement :
```bash
chmod +x launch.sh
./launch.sh
```

Utilisez `agents/voice_assistant.py` pour interagir avec le projet à la voix.# mcp-fastapi-agent
